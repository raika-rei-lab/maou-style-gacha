# 🎰 MAOU STYLE GACHA 24

**ChatGPTの画像生成で遊ぶための、非公式スタイルキーワードメーカー。**

24種類の日本語ボタンを好きなだけ選択し、必要なら自由にお願いを書いてコピー。ChatGPTに貼り付けて画像ガチャを楽しめます。スラッシュ指定はChatGPTの公式コマンドではありません。

## 使い方

1. `index.html` をChromeなどのブラウザで開く（または公開サイトへアクセス）。
2. スタイルを選択（複数可）。全部選択・全解除・おまかせ3つにも対応。
3. 必要なら日本語で追加のお願いを書く。スラッシュ・英単語・英文の形式を選んでコピー。
4. ChatGPTへ貼り付ける。参照画像を使う場合はChatGPTで添付する。

## ファイル

- `index.html` — 完成した単一HTML（CSS・JavaScriptを内包、依存ライブラリなし）
- `SPEC.md` — 設計仕様書と受入条件
- `QA.md` — QAの実施内容と制限

## 安全性と費用

API、CDN、外部通信、解析タグ、入力の自動保存なし。コピーは手動操作。ページ上で画像は生成されません。ツール自体は無料ですが、ChatGPT側のプラン・回数制限・費用は別です。公開サーバーにはアクセスログが残る場合があります。

## note制作記事のリンク

**記事公開前はリンクを表示しません。** 公開後に `index.html` 内の次の定数にURLを設定してください。

```js
const ARTICLE_URL = 'https://note.com/ユーザー名/n/記事ID';
```

HTTPSの `note.com` でなければ案内は表示しません。リンクを設定すると、制作の裏話と「感想・不具合は記事のコメント欄へ」の案内が表示されます。
